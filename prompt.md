# Build prompt

Build a make.fun bounty entry for "Seventeen Syllables of Debugging"
(competition u-irvan-motion-seventeen-syllables-of-debugging-d194b605): one
haiku about debugging — exactly 17 syllables in the 5-7-5 shape, three
lines, at most 200 characters — written by a Node program (main.ts, no
dependencies) to /output/entry.txt.

Invent the haiku from scratch in-session: funny and sharp, something a
judge will remember. The centre picture must be concrete (a breakpoint, a
log line, a cursor at 3am), the last line must turn the poem and reframe
what came before, every word must earn its place, and it must read aloud
like speech rather than a syllable exercise. Verify the syllable count of
each line by hand (5, then 7, then 5).

Include a validation guard (exactly 3 non-blank lines, 1–200 characters)
in main.ts, run it twice and verify byte-identical output. Ship LICENSE
(MIT), README.md, prompt.md, and .makefun/owner.json with the payout
wallet, and publish the repo publicly on GitHub.
